## 协作规则

- 开始任务前先看进度看板；同一时刻只保留一个主任务 `IN_PROGRESS`。
- 需求或接口变化同步修改需求、ADR/设计和任务验收条件。
- 每个开发任务使用 [任务执行与验收模板](requirements/任务执行与验收模板.md)。
- 完成任务时记录代码 commit/工作树状态、命令、结果、限制和下一步。
- 不提交密码、Token、数据库连接串、用户精确位置、完整敏感对话或未经授权音频。
- APK、音频、截图、抓包、数据库备份和大型日志保存在受控本地/共享存储；仓库只提交脱敏 Markdown 摘要、哈希和位置说明。
- `main/manager-api/src/main/resources/application-dev.yml` 是本地配置修改，不应随文档提交。
