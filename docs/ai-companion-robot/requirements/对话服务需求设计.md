# 对话服务需求设计



# 一、知识库

1. 知识库内容

1）使用整理好的小品、笑话等文档，构建基础幽默段子知识库。

2）加入其它希望机器人掌握的特定知识。



2. 知识库管理

1\) 现有知识库增删改查后台管理。

2\) 目标网站内容自动入库。



# 二、长期记忆

1. 基本功能实现。

2. 数据存储方案。

3. 个人信息结构化存储。

4. 遗忘策略。

5. 系统级查询和修改。



# 三、性格设定

1、性格维度设计。

2、性格维度内容转换为提示词内容。



# 四、对话能力

1、对接豆包语音2\.0\.

2、对接其它流式语音。

3、部署本地模型（云服务器）。

4、测试Gemini和OpenAI文本问答API。

5、主动发起对话的能力。

6、用户打断能力。



# 五、搜索能力

1、整理信息源。

2、根据意图，决定搜索目标网址。

3、搜索内容整理成回答内容，要结合长期记忆（如何？）



# 六、安卓客户端

1、部署测试。

2、根据对话内容，显示相应表情。

3、与ESP32和其它单片机通讯。

4、控制眼球转动。

5、驱动开发。

6、用户打断能力。
