# AI 陪伴机器人需求追踪矩阵

> 版本：v0.1（2026-08-22 增补）  
> 用途：连接概要需求、详细设计、开发阶段和验收证据。`待细化` 表示需求已识别，但在依赖信息确认前不能冻结验收值。

## 状态定义

- `已覆盖`：详细设计和开发阶段已有对应内容。
- `部分覆盖`：已有方向，但接口、阈值、供应商或产品规则仍需确定。
- `待设计`：需在后续阶段补充专项设计。
- `待决策`：依赖 P0/P1 澄清答案。

## 当前缺口汇总

1. 尚无参考开源项目，无法确认代码复用、接口兼容和许可证义务。
2. 尚无目标硬件规格，音频、动作、通信和 OTA 设计无法冻结。
3. 部署地区与数据跨境规则未定，模型供应商和数据架构不能冻结。
4. 首期功能边界、团队与日期未定，开发计划只能给出相对阶段和人周范围。
5. 产品指标尚无基准数据，验收栏目前定义了证据类型，但多数数值需在 M0 基准后确定。
